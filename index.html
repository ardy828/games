Games

Two games, each a single self-contained HTML file — no build step, no dependencies, no bundler. Open the file and it runs. Click either one to play.

TOP-DOWN SHOOTER SCRAPLINE

Hold a scrapyard against malfunctioning salvage drones closing from every bearing. Mouse-aimed, endless procedurally varied waves, 26 upgrades picked three at a time, and a boss with four attacks. Sound is synthesised in the browser.

PLAY → SLIDING PUZZLE CHALLENGER DEEP

Every tile is a depth in metres. Merge equal depths to sink from the sunlight zone toward the trench floor at 10,935 m, watching the pressure gauge climb and the ocean zones change around you.

Run either locally with python3 -m http.server 8000 from its folder, then open localhost:8000. Both are plain static HTML, so any web host will serve them as-is.
